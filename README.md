# qiqstr for iOS

**A native SwiftUI port of [qiqstr](https://github.com/untreu2/qiqstr), the Nostr client with a built-in Lightning wallet.**

</div>

qiqstr for iOS keeps the Flutter app's Rust core and replaces the Flutter UI with native SwiftUI built for iOS 26 and Liquid Glass. The design language is unchanged: monochrome, Poppins wordmark, capsule buttons, rounded icon tiles, and the familiar interaction colours. Navigation, sheets, toolbars, the tab bar and controls are all system-native.

## Rust ↔ Swift

The Rust core (nostr-sdk 0.44, LMDB, NIP-17, NWC, Cashu) is shared with the Flutter app and exposed to Swift with [UniFFI](https://mozilla.github.io/uniffi-rs/):

- `rust/src/api/` is the Flutter app's Rust API, without flutter_rust_bridge annotations.
- `rust/src/ffi.rs` is generated by `scripts/gen_ffi.py`. It exports every API function with `#[uniffi::export]`, runs async work on a dedicated Tokio runtime, and maps `anyhow` errors to a typed `QiqError`.
- Streams (relay subscriptions, broadcasts, profile backfills) use a foreign `EventSink` callback that Swift exposes as an `AsyncThrowingStream`.
- `scripts/build-rust.sh` builds `QiqstrCoreFFI.xcframework` and generates the Swift bindings into the local `QiqstrCore` Swift package.

## Building

Requirements: Xcode 26+, Rust with the `aarch64-apple-ios` and `aarch64-apple-ios-sim` targets, and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
scripts/build-rust.sh        # release XCFramework for device and simulator
xcodegen generate
open Qiqstr.xcodeproj
```

For faster simulator-only iteration, run `PROFILE=dev TARGETS=aarch64-apple-ios-sim scripts/build-rust.sh`.

## Features

- Account creation with a seed phrase backup, login with nsec, hex key or mnemonic, multiple accounts with instant switching, and logout.
- Onboarding: key backup, profile setup with Blossom image upload, and suggested follows.
- Home feed with follow-set feeds, sorting, realtime updates and paging; threads, quotes and note statistics.
- Notes: rich content with mentions, hashtags, media, link previews, and embedded notes and articles. Like, repost, quote, reply, zap, bookmark, pin, report, mute and delete.
- Compose with mention autocomplete and media upload.
- Profiles with notes, replies, photos and likes, follow lists, NIP-05 verification, profile editing, and a QR share card.
- NIP-17 encrypted direct messages, including encrypted media.
- Wallet: Nostr Wallet Connect, Lightning addresses and LNURL, invoices with QR codes, Cashu redeem, and NIP-57 zaps.
- Notifications grouped by note, with filters.
- Reads (NIP-23 articles with a markdown renderer), user search, encrypted bookmarks, and NIP-51 lists.
- Settings: keys with Face ID reveal, relays with live status and a NIP-65 relay list, muted users and words (encrypted), theme, language (English, Turkish, German), database cache, and event manager with rebroadcast, export and NIP-62 request to vanish.

The Flutter app's Breez Spark wallet needs a Breez API key and is not included. The wallet backend is behind a protocol so Spark can be added later.
