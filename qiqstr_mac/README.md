# qiqstr for macOS

A native macOS client for qiqstr, built with SwiftUI on the shared Rust core (`../qiqstr_rust`). It reuses the iOS app's code from `../qiqstr_swift` with a Mac window: a sidebar for Home, Messages, Notifications, Search, Wallet, Profile, Reads, Live, Lists and Bookmarks, a toolbar compose button, and menu shortcuts (⌘N new post, ⌘Return to post, ⌘1–⌘7 sections, ⌘[ back, ⌘, settings, ⇧⌘A switch account), Return to send in messages.

See `AGENTS.md` for build steps.
