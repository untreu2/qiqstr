- Profile photo and identity share a leading edge, with the photo border extending outward. Actions align beside the photo and move to a separate row when space is insufficient.
- Long names and profile details wrap; accessibility text sizes stack identity and follow counts. Badges use an adaptive grid. The collapsed navigation identity follows the measured header position.

The encrypted-backup UI remains unverified past the simulator authentication gate from the interrupted session. Clean builds still report pre-existing Swift concurrency warnings outside this change.
